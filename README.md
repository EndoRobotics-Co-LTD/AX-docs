# AX-docs — EndoRobotics AX 교육 자료

EndoRobotics 임직원을 위한 **AX(AI 전환·활용) 교육 세미나** 핸드북입니다.
AI 에이전트의 개념과 철학, 하네스(harness) 원리, 그리고 Claude Code·Cowork 같은
AI 에이전트 도구의 실제 사용법을 다룹니다.

🔗 **온라인으로 보기 →** https://endorobotics-co-ltd.github.io/AX-docs/

---

## 무엇인가

매 강의 세션마다 내용을 아래로 누적해 나가는 **위키독스 형태의 단일 핸드북**입니다.

- **단일 HTML 파일**(`index.html`) — CSS·JS가 모두 인라인되어 외부 의존성이 없습니다. 파일 하나만으로 오프라인에서도 그대로 열립니다.
- 좌측 **사이드바 목차 + 실시간 검색**, 강의 절(節) 단위 **페이지네이션**(스크롤이 아닌 페이지 전환).
- 터미널 명령어는 **한 번에 복사** 버튼 제공.

## 현재 내용 — 제1강 「AI 에이전트란?」

| 절 | 주제 | 한 줄 요약 |
|---|---|---|
| 1.1 | AI 활용 철학 | 본질은 'AI가 만든 도구'가 아니라 **AI 그 자체**에 있다 |
| 1.2 | AI 서비스 종류 | claude.ai · Cowork · Claude Code · API — 서비스 형태별 차이 |
| 1.3 | 하네스(Harness)란? | 모델을 감싸 실제로 일하게 만드는 주변 구조물 |
| 1.4 | 하네스의 구조 | 자체 메모리 · SOFT · HARD 하네스 + 생태계 용어(API·MCP·커넥터·플러그인) |
| 1.5 | 기초 사용법 — Cowork | 비개발자용. 클릭 설치, 기초적인 SOFT 하네스 |
| 1.6 | 기초 사용법 — Claude Code | 개발자용. Windows 설치(Git·환경변수)·오류 해결·물리 구조·첫 실행 |

## 앞으로 추가될 내용

세션이 진행될 때마다 이 핸드북 아래로 강의가 누적됩니다.

- **제2강 — 심화 활용 (하네싱 실전)**: 직접 하네스를 씌우는 방법
  — `CLAUDE.md`, 권한(permissions), MCP·커넥터, 훅(hooks), 서브에이전트, 스킬·슬래시 커맨드, 컨텍스트 관리.
- **이후 세션(예정)**: 검증·평가 루프, 부서별 AX 적용 사례, 멀티 에이전트 오케스트레이션 등.

## 업데이트 방법

이 사이트는 GitHub Pages로 호스팅되며, `main` 브랜치 루트의 `index.html`을 그대로 서빙합니다.

```bash
# index.html 수정 후
git add index.html
git commit -m "Update: <변경 내용>"
git push origin main
# → 약 30~60초 후 위 URL에 자동 반영
```
